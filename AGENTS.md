# Scope
Preserve the frozen paper and challenge protocols. Never tune settings from reproduction results.
Keep all large assets and outputs under the configured storage1 directory. Do not copy credentials or raw caches into Git.
Default commands inspect or aggregate existing evidence. GPU inference is an explicit command, never a side effect of reporting.
Historical outputs are read-only. Write new runs to a fresh directory; bind resumes to configuration and checkpoint hashes.
Single-GPU inference uses one process. Do not run network submission, background campaigns or Git publishers from this repository.
